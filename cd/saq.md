# UNIT – I : 8086 Microprocessor

### 1. Define 8086 microprocessor.

8086 is a 16-bit microprocessor developed by Intel used for processing data and executing instructions.

---

### 2. What is memory segmentation in 8086?

Memory segmentation divides memory into smaller sections like code, data, stack, and extra segments.

---

### 3. What is the function of Program Counter in 8086?

Program Counter stores the address of the next instruction to be executed.

---

### 4. What are flags in 8086?

Flags are status indicators that show results of arithmetic and logical operations.

---

### 5. What is the difference between minimum mode and maximum mode?

Minimum mode is used for single processor systems, while maximum mode is used for multiprocessor systems.

---

### 6. Define addressing mode.

Addressing mode is the method used to access operands in memory or registers.

---

### 7. What is a macro in assembly language?

A macro is a group of instructions represented by a single name for repeated use.

---

### 8. What is an interrupt in 8086?

Interrupt is a signal that temporarily stops normal execution to handle an important event.

---

# UNIT – II : 8051 Microcontroller

### 9. Define microcontroller.

A microcontroller is a compact integrated circuit containing CPU, memory, and I/O ports on a single chip.

---

### 10. What is 8051 microcontroller?

8051 is an 8-bit microcontroller widely used in embedded systems and automation applications.

---

### 11. How many I/O ports are available in 8051?

8051 contains four 8-bit I/O ports.

---

### 12. What is the function of timers in 8051?

Timers are used for delay generation, counting operations, and baud rate generation.

---

### 13. Define addressing mode in 8051.

Addressing mode specifies how operands are accessed during instruction execution.

---

### 14. What is serial communication in 8051?

Serial communication transfers data one bit at a time between devices.

---

### 15. What is the role of interrupts in 8051?

Interrupts help the processor respond quickly to external or internal events.

---

### 16. What is the function of accumulator register?

Accumulator stores results of arithmetic and logical operations.

---

# UNIT – III : Communication Interfaces

### 17. Define serial communication.

Serial communication is the transmission of data one bit at a time between devices.

---

### 18. What is synchronous communication?

Synchronous communication uses a common clock signal between sender and receiver.

---

### 19. What is asynchronous communication?

Asynchronous communication transfers data without using a common clock signal.

---

### 20. Expand I2C.

I2C stands for Inter-Integrated Circuit.

---

### 21. What are SDA and SCL lines in I2C?

SDA is the data line and SCL is the clock line.

---

### 22. Expand SPI.

SPI stands for Serial Peripheral Interface.

---

### 23. What is UART?

UART is a hardware communication protocol used for asynchronous serial communication.

---

### 24. What is RS232?

RS232 is a serial communication standard used for data transfer between devices.

---

# UNIT – IV : ARM Architecture

### 25. Expand ARM.

ARM stands for Advanced RISC Machine.

---

### 26. What is RISC architecture?

RISC architecture uses simple instructions for faster execution.

---

### 27. What is CPSR in ARM?

CPSR stands for Current Program Status Register which stores status and control information.

---

### 28. What is pipelining in ARM?

Pipelining is the process of executing multiple instructions simultaneously in stages.

---

### 29. Define interrupt vector table.

Interrupt vector table stores addresses of interrupt service routines.

---

### 30. What is a branch instruction?

Branch instruction changes the normal sequence of program execution.

---

### 31. What is conditional execution in ARM?

Conditional execution allows instructions to execute only when certain conditions are satisfied.

---

### 32. What are Thumb instructions?

Thumb instructions are compressed 16-bit ARM instructions used to reduce memory usage.

---

# UNIT – V : Advanced ARM Processors

### 33. What is Cortex processor?

Cortex processor is an ARM-based processor family designed for embedded and mobile systems.

---

### 34. Name the Cortex processor families.

Cortex-A, Cortex-R, and Cortex-M are the main Cortex processor families.

---

### 35. What is Cortex-M mainly used for?

Cortex-M is mainly used in embedded and microcontroller applications.

---

### 36. What is OMAP processor?

OMAP is a multimedia processor platform combining ARM processor and DSP technology.

---

### 37. Expand OMAP.

OMAP stands for Open Multimedia Application Platform.

---

### 38. What is DSP in OMAP processor?

DSP stands for Digital Signal Processor used for multimedia and signal processing.

---

### 39. Mention one application of Cortex processor.

Cortex processors are used in smartphones and embedded systems.

---

### 40. Mention one advantage of OMAP processor.

OMAP processor provides efficient multimedia and graphics performance.
