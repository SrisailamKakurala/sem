# UNIT – I : 8086 Microprocessor Jargons

**8086** – A 16-bit Intel microprocessor used in early computer systems.

**Microprocessor** – A programmable electronic chip that performs processing tasks.

**Architecture** – Internal design and organization of a processor.

**Functional Diagram** – Block diagram showing working parts of the processor.

**Register** – Small high-speed storage location inside CPU.

**Flag Register** – Register that stores status information after operations.

**Carry Flag** – Indicates carry generated in arithmetic operations.

**Zero Flag** – Indicates result is zero.

**Sign Flag** – Indicates result is negative.

**Overflow Flag** – Indicates arithmetic overflow.

**Memory Segmentation** – Dividing memory into smaller logical sections.

**Code Segment** – Stores program instructions.

**Data Segment** – Stores data values.

**Stack Segment** – Stores temporary data and return addresses.

**Offset Address** – Address relative to segment base.

**Physical Address** – Actual memory address generated by processor.

**Pin Diagram** – Diagram showing pins and their functions.

**Minimum Mode** – Operating mode for single processor system.

**Maximum Mode** – Operating mode for multiprocessor system.

**Timing Diagram** – Graphical representation of signal timing.

**Interrupt** – Signal that temporarily stops program execution.

**Instruction Format** – Structure of machine instruction.

**Addressing Mode** – Method of accessing operands.

**Assembler Directive** – Commands used by assembler during program translation.

**Macro** – Group of instructions represented by one name.

**String Manipulation** – Operations performed on character data.

# UNIT – II : 8051 Microcontroller Jargons

**8051** – Popular 8-bit microcontroller used in embedded systems.

**Microcontroller** – IC containing CPU, memory, and I/O ports.

**ALU** – Arithmetic Logic Unit that performs calculations and logical operations.

**ROM** – Read Only Memory used to store programs.

**RAM** – Random Access Memory used for temporary storage.

**I/O Port** – Interface for communication with external devices.

**Accumulator** – Main register used for arithmetic operations.

**Timer** – Hardware used for counting and delay generation.

**Counter** – Circuit used to count external events.

**Serial Communication** – Data transfer one bit at a time.

**Interrupt** – Event that requests immediate processor attention.

**Addressing Modes** – Methods used to access data.

**Immediate Addressing** – Data is directly given in instruction.

**Direct Addressing** – Address of data specified directly.

**Indirect Addressing** – Address stored inside register.

**Indexed Addressing** – Address calculated using index register.

**Baud Rate** – Speed of serial communication.

---

# UNIT – III : Communication Interface Jargons

**Serial Communication** – Transmission of data bit by bit.

**Parallel Communication** – Transmission of multiple bits simultaneously.

**Synchronous Communication** – Communication using common clock signal.

**Asynchronous Communication** – Communication without common clock.

**I2C** – Two-wire communication protocol.

**SDA** – Serial Data Line in I2C.

**SCL** – Serial Clock Line in I2C.

**Master Device** – Device controlling communication.

**Slave Device** – Device responding to master commands.

**SPI** – High-speed serial communication protocol.

**MOSI** – Master Out Slave In data line.

**MISO** – Master In Slave Out data line.

**SCLK** – Clock signal in SPI.

**SS (Slave Select)** – Signal used to select slave device.

**UART** – Universal Asynchronous Receiver Transmitter.

**RS232** – Serial communication standard for computers and devices.

**USB** – Universal Serial Bus used for modern device communication.

**Protocol** – Set of communication rules.

**Full Duplex** – Simultaneous transmission and reception.

---

# UNIT – IV : ARM Architecture Jargons

**ARM** – Advanced RISC Machine processor architecture.

**RISC** – Reduced Instruction Set Computer.

**Pipeline** – Technique for executing multiple instructions simultaneously.

**Fetch** – Reading instruction from memory.

**Decode** – Understanding instruction operation.

**Execute** – Performing instruction operation.

**CPSR** – Current Program Status Register.

**Condition Flags** – Bits showing operation results.

**IRQ** – Interrupt Request.

**FIQ** – Fast Interrupt Request.

**Exception** – Event interrupting normal execution.

**Interrupt Vector Table** – Table storing addresses of interrupt handlers.

**Branch Instruction** – Instruction that changes execution flow.

**Load Instruction** – Reads data from memory.

**Store Instruction** – Writes data to memory.

**Conditional Execution** – Executing instruction only if condition is true.

**Thumb Instruction** – Compressed 16-bit ARM instruction.

**SWI** – Software Interrupt instruction.

**Link Register** – Register storing return address.

---

# UNIT – V : Advanced ARM Processor Jargons

**CORTEX Processor** – ARM processor family for embedded and mobile systems.

**Cortex-A** – Processor family for high-performance applications.

**Cortex-R** – Processor family for real-time systems.

**Cortex-M** – Processor family for microcontroller applications.

**OMAP** – Open Multimedia Application Platform.

**DSP** – Digital Signal Processor used for multimedia processing.

**Embedded System** – Dedicated system designed for specific tasks.

**Cache Memory** – High-speed memory storing frequently used data.

**Multimedia Processing** – Processing audio, video, and graphics data.

**Real-Time System** – System responding within fixed time limits.

**NVIC** – Nested Vector Interrupt Controller.

**Low Power Consumption** – Using minimal electrical power.

**Multitasking** – Running multiple tasks simultaneously.

**Bus Interface** – Communication path between components.

**Graphics Processing** – Processing images and visual data.

**Instruction Set** – Collection of processor instructions.
